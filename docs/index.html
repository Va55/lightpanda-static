STATUS: frozen. This is a capability demonstration, not a maintained target. The 32-bit port was proven and archived at r3 (v1.0.3-main.20261106-r1, 2026-11-07) — no further releases are planned, and no security updates will be issued. Not a fork, not a distribution, no support — if upstream ships static builds, this repo is obsolete by design. Read the reasoning in the README status banner.

Fully static Lightpanda builds for x86_64 and the i386 (32-bit x86 / i686) port — zero glibc, no libc-loader needed at runtime. They run on any Linux regardless of distro: Alpine/musl, Debian/Ubuntu/glibc, distroless. A usable browser hand-built for the 32-bit world, plus the full build recipe.

CI-built, stripped, reproducible: built by the repo workflow on a self-hosted runner, twice, and the run fails unless both passes are byte-identical. The release is immutable and carries Sigstore build provenance. Built from upstream main @ 8678e04 (tag 1.0.3 + 209 commits). Earlier assets are kept for lineage.

Built from upstream lightpanda-io/browser main @ f734e7f (2026-10-18 — the 1.0.1 line plus 91 commits). Releases are named <release line>-r<build>, not after the version string: lightpanda version prints 1.1.0-dev, which is upstream's next-development string and is identical across upstream tags 1.0.1, 1.0.2 and 1.0.3. Pins: VERSIONS.md.

Note: the 32-bit asset file is named i686 (its real ISA floor). "i386" is the human-facing label for 32-bit x86, as Debian uses it. The floor is SSE2 (Pentium 4 / Athlon 64 / Core Duo and newer): V8's ia32 build aborts without it (Check failed: cpu.has_sse2()), and it is verified working on a real Core Duo L2500.

Install & verify

sudo install -m 0755 lightpanda-*-musl /usr/local/bin/lightpanda
lightpanda version                  # 1.1.0-dev (upstream next-dev string, not the tag)
file /usr/local/bin/lightpanda      # "... statically linked ..."
readelf -d /usr/local/bin/lightpanda | grep -c NEEDED   # 0
lightpanda fetch --dump semantic_tree_text https://example.com

What's here

  • Full build recipe — see build/README.md, with the pinned environment in build/Dockerfile and build/toolchain.lock.
  • CI workflows — build twice and compare, then attest; and attest release assets.
  • patches/ — the actual i386 source delta: the zig-v8-fork GN-args patch and the 17-file Lightpanda 32-bit port (+113/−47).
  • musl_glibc_shim.c — a small glibc-symbol compat layer folded into the V8 archive so Lightpanda links pure-musl (one unconditional shim for both arches).
  • i386 port: the capability toolchain carries directly to an i386 Chromium if it's ever needed.
